The goal for this problem is to not have to touch each element more than once. Anything beyond that is redundant. To do this, I broke each value into one of three arrays based on if it was smaller than, equal to, or greater than the pivot number. This has the bonus of also ensuring that we maintain the relative order of the values as they come in. The requirement to maintain the relative order of the values actually works in our favor in this case. Because the order must be preserved, it means that it behooves us to append the values onto the end of the arrays. This is more efficient anyway, because appending an element is a O(1) operation. While that operation is O(1), each element in the array still must be compared, so this still remains an O(N) operation.
